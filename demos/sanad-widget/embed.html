Add a support chat to any website with one line

Sanad answers customers from your FAQ file with an Arabic-aware fuzzy matcher (no AI API, no server), then hands over to WhatsApp with the conversation summary when it is unsure.

Embed code

Paste before </body>. It updates as you change the playground below.

Live config playground

Every change re-mounts the widget on this page.

Attributes

data-faqURL of your FAQ JSON (questions in several phrasings, answer, follow-up chips).
data-whatsappNumber for the “Talk to a human” hand-off, digits only.
data-langar (RTL) or en (LTR).
data-name, data-colorBot name and brand colour.
data-hours, data-days, data-tzWorking hours, e.g. 09:00-21:00, 0,1,2,3,4,6 (Sun=0), Asia/Gaza.
data-thresholdMatch confidence (0–1). Below it the bot asks “Did you mean…?”.

Matcher inspector

Type a question in any dialect or with typos and see the normalised tokens and the top scores, the same code the widget runs.
